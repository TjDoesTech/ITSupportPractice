# <h1>IT Support - Practice</h1>

<h2>Description</h2>
This project exists to show case how I have been trying to practice IT support from home. There is a website called ServiceDesk Simulator which simulates a real time IT MSP and ticketing environment. This allows me to handle tickets and learn to solve problems that will commonly show up in an actual professional setting.
